# Changelog - CleanAd (Systemless Host Protection)
Pengembang: Ithra JB

---

## v1.3-Stabil
* Pembaruan Database: Memperbarui daftar host untuk memblokir server iklan terbaru dari Google, Unity, dan AppLovin.
* Keamanan Modul: Menambahkan sistem proteksi anti-modifikasi rahasia (MD5 Checksum) untuk mencegah pembajakan modul.
* Optimasi Script: Mempercepat proses instalasi modul di aplikasi Magisk.
* Peningkatan Privasi: Penambahan filter khusus untuk memblokir tracker (pelacak) aplikasi pihak ketiga di latar belakang.
* Fitur Baru: Otomatis mengarahkan pengguna ke channel YouTube Ithra JB untuk panduan resmi dan update.

## v1.2-Stabil
* Rilis Perdana: Peluncuran versi awal CleanAd.
* Fitur Utama: Memblokir iklan, tracker, dan malware secara systemless (tidak merusak sistem OS asli).
* Kompatibilitas: Mendukung semua perangkat Android dengan akses root Magisk (Universal).
* Efisiensi: 100% berjalan tanpa memakan kapasitas RAM (Zero RAM Usage).
